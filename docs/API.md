# API Reference

All routes are served through Nginx at `http://localhost:8080/api` in the local docker-compose environment. JSON in, JSON out. Authenticated routes take `Authorization: Bearer <token>`.

Every response follows `{ success: boolean, data?, message?, code?, pagination? }`.

## Auth

| Method | Path | Auth | Body | Notes |
|---|---|---|---|---|
| POST | `/auth/register` | - | `{email, password, name}` | Bloom-filter-accelerated duplicate check |
| POST | `/auth/login` | - | `{email, password}` | Rate limited 5/min/IP. Returns `{token, user}` |
| POST | `/auth/logout` | Bearer | - | Clears the Redis session record |
| GET | `/auth/me` | Bearer | - | |

## Events

| Method | Path | Auth | Notes |
|---|---|---|---|
| GET | `/events?page=&pageSize=&category=` | - | Reads from a replica |
| GET | `/events/:id` | - | Bloom filter + cache-aside |
| POST | `/events` | Admin | Creates the event AND its full `event_seats` inventory |
| PUT | `/events/:id` | Admin | Partial update, invalidates cache |
| DELETE | `/events/:id` | Admin | Soft-cancels (`status = CANCELLED`) |

## Seats

| Method | Path | Notes |
|---|---|---|
| GET | `/events/:eventId/seats` | Full seat map with per-seat status |
| GET | `/events/:eventId/availability` | Cached counts by status |
| GET | `/events/:eventId/stream` | Server-Sent Events - `seat-update` events pushed on any seat/booking change for this event |

## Holds

| Method | Path | Auth | Body |
|---|---|---|---|
| POST | `/events/:eventId/seats/hold` | Bearer | `{seatId}` -> 201 or 409 |
| DELETE | `/events/:eventId/seats/hold` | Bearer | `{seatId}` |

Rate limited 20/min/user. Proxied to the Booking Service, which owns the distributed lock + transaction.

## Bookings

| Method | Path | Auth | Notes |
|---|---|---|---|
| POST | `/bookings` | Bearer + `Idempotency-Key` header (required) | `{eventId, seatIds[]}` -> 201 (new) or 200 (idempotent replay) |
| GET | `/bookings?all=true` | Bearer | `all=true` requires ADMIN, otherwise scoped to the caller |
| GET | `/bookings/:id` | Bearer | Owner or admin only |
| POST | `/bookings/:id/cancel` | Bearer | Releases seats back to AVAILABLE |

## Search

| Method | Path | Notes |
|---|---|---|
| GET | `/search/events?q=&category=&city=&date=&minPrice=&maxPrice=&page=&pageSize=` | Proxies to the Search Service (OpenSearch) |

## Analytics (admin only)

| Method | Path |
|---|---|
| GET | `/analytics/events/:eventId` |
| GET | `/analytics/dashboard` |

## Admin

| Method | Path |
|---|---|
| GET | `/admin/users?page=&pageSize=` |
| GET/POST | `/venues` (POST is admin-only; creates a venue + sections + seats in one call) |

## Health / Ops

| Method | Path | Notes |
|---|---|---|
| GET | `/health` | Liveness |
| GET | `/ready` | Readiness - checks DB + Redis + replica health |
| GET | `/metrics` | Prometheus exposition format |

Every response carries `X-Request-ID` (generated by Nginx or the client, echoed by every hop) for tracing a single request across API -> Booking Service -> Redis -> Postgres -> RabbitMQ -> a worker/consumer.
